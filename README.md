# Blood Strike × B2K — Strikers Hub

A fan-made community information hub for Blood Strike, created by B2K.

## Website
The website is a static HTML page. GitHub Pages can host it without a build step.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Choose **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then press **Save**.
5. Wait a few minutes. The expected URL is https://tosingodwin18-pixel.github.io/Blood-strike-x-B2K-/
